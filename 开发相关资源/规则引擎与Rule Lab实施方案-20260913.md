## 2. 规则 Schema (v1)

```jsonc
{
  "id": "everia-club",            // 全局唯一,CDN 文件名 = id + ".json"
  "version": 1,                    // 规则版本,与 App 版本解耦
  "name": "Everia.club",
  "match": {
    "hostIn": ["everia.club"],
    "urlRegex": "^https?://(www\\.)?everia\\.club/.*/\\d+/?$"
  },
  "fetch": {
    "userAgent": "...",
    "headers": { "Referer": "" }
  },
  "extract": {
    "title":    { "selectors": ["h1.entry-title", "h1", "title"], "attr": "text" },
    "images": [
      { "selectors": ["div.gallery a"], "attr": "href", "toAbsolute": true, "minWidth": 600 },
      { "selectors": ["article img"], "attr": "src",
        "fallbackAttrs": ["data-src", "data-lazy-src", "data-original"],
        "srcsetAttr": "srcset" }
    ],
    "nextPage": { "selectors": ["a.next.page-numbers", "link[rel=next]"], "attr": "href" }
  },
  "pagination": { "maxPages": 20, "stopOn": "noImages" },
  "imageFilter": {
    "exclude": [{ "selector": ".avatar" }, { "selector": ".ads" }],
    "minWidth": 400,
    "minArea": 400 * 400
  }
}
```

引擎实现要点:
1. 极简 CSS 选择器子集:`tag / .cls / #id / [attr=v] / tag.cls / 后代 / a, b`,不引重型库。
2. `fallbackAttrs` 解决懒加载;`srcset` 选最接近 viewport 的那张。
3. 所有 `<a href>` / `<img>` 相对 URL 用 `new URL(href, baseUrl)` 绝对化。
4. `imageFilter.exclude` 在选择器阶段就过滤;`minWidth` 在图片 onLoad 后过滤。
5. `nextPage` 喂给现有 `parseWebArticle` 翻页循环(已有实现,零重写)。
6. 失败/无规则 → 走 ③ 通用启发式:og:image / twitter:image / `<article>` 内 `<img>` / `<picture><source srcset>`。

### 5.3 启发式引擎算法(`tools/rule-engine/src/heuristic.ts`)

```ts
function autoDetect(html: string, baseUrl: string): CandidateRule {
  const doc = parseHTML(html);

  // 1) 标题候选(按优先级)
  // h1, .entry-title, .post-title, article header h1, og:title, <title>
  // 取文本最长且非空、非纯数字

  // 2) 图片候选(聚类 + 黑名单过滤)
  // 所有 <img> → 取 src/data-src/data-lazy-src/data-original/srcset
  // 排除 class 匹配 /(avatar|logo|emoji|icon|spinner|placeholder)/i
  // 排除 width/height < 200 或 role="presentation"
  // 找"最连续的父节点"——同一个 <div>/<figure> 下连续多图视为图集
  // 检查 <a> 包裹:取 href 作原图链接
  // 输出选择器形如 "article .gallery img"

  // 3) 翻页候选
  // link[rel=next], a.next, a.page-numbers.next, .pagination a.next, .nav-links a.next
  // URL 模板探测:/2/、?page=N、?paged=N(HEAD 探测 {n}=2 是否 200,仅 fetch 时)

  // 4) 黑名单(imageFilter.exclude)
  // .avatar, .logo, .ads, .advertisement, [role="presentation"]
  // minWidth: 400, minArea: 400*400

  // 5) 拼成 RuleSchema
  return { id, version: 1, name, match, extract, pagination, imageFilter };
}
```

## 6. GitHub Issue 提交与 Bot 验证

### 6.1 前端提交 Issue(`docs/index.html`)

```js
async function submitIssue(rule, meta) {
  const pat = localStorage.tgimg_gh_pat;
  const repo = 'mationchen/TgImagesDownloader-extractors';
  const body = `
### 新规则提交

**站点**: ${rule.name} (${rule.id})
**URL 测试**: ${meta.testUrl}
**抓取图片数**: ${meta.imageCount}
**启发式评分**: ${meta.heuristicScore}

\`\`\`json
${JSON.stringify(rule, null, 2)}
\`\`\`

<!-- bot-validate -->
`;
  const resp = await fetch(`https://api.github.com/repos/${repo}/issues`, {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${pat}`,
      'Accept': 'application/vnd.github+json',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      title: `[rule] ${rule.id} v${rule.version}`,
      body,
      labels: ['new-rule'],
    }),
  });
  return resp.json();
}
```

### 6.2 Bot 验证 Workflow(`.github/workflows/validate-rule.yml`)

```yaml
on:
  issues:
    types: [opened, edited]

jobs:
  validate:
    if: contains(github.event.issue.labels.*.name, 'new-rule')
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '22' }
      - name: Extract rule JSON from issue body
        id: extract
        run: echo "RULE=$(node tools/extract-rule.mjs '${{ github.event.issue.body }}')" >> $GITHUB_OUTPUT
      - name: Validate JSON schema + fetch test URL
        run: node tools/validate-rule.mjs "${{ steps.extract.outputs.RULE }}" "${{ github.event.issue.body }}"
      - name: Comment results back
        uses: marocchino/sticky-pull-request-comment@v2
        with:
          message: |
            ## 🤖 Bot 验证结果
            ✅ JSON schema 通过
            ✅ 抓取 N 张图片
            ✅ 翻页链接 200
            ❌ 失败项(如有)
            Maintainer 确认后可合入。
```

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| OpenAI/Anthropic 浏览器 CORS 限制 | v1 默认 Gemini;提供 `customBase` 让高级用户用 |
| 启发式对反爬/重 JS 站点无效 | v1 明确"复制渲染后 HTML";v2 加 Puppeteer 后端或浏览器扩展 |
| Bot workflow 误报 | 规则 `imageCount >= 1` 才算有效;Maintainer 复核 |
| jsDelivr 缓存延迟 | publish.yml 加 `purge-cache` 步骤 |
| 用户 PAT 泄露 | 仅 localStorage;明示不上传任何服务器 |
| GitHub PAT scope 误用 | 文档明确"只需要 `public_repo` scope,请勿给其他权限" |
| 启发式引擎解析慢(页面卡顿) | 文档大小 > 5MB 时提示截取 `<main>` 部分 |
| 极简选择器不够用 | 后续可扩 `:nth-of-type` 等;目前仅支持基础子集 |
